AI 产品更新

PowerMem 1.1.x

让 Coding Agent 不再“失忆”，PowerMem 1.1.x 持续升级长期记忆、IDE 集成与会话观测能力。

PowerMem 连续发布 v1.1.1–v1.1.7 七个版本，主要围绕 IDE / Claude Code 集成、Dashboard 检索与观测、零配置与 no-LLM 部署、中文化文档、MCP / 插件发布体验，以及记忆检索与生命周期稳定性持续增强。

  • v1.1.1：新增 IDE 集成与 MoonBit HTTP API 示例，补强 Dashboard 回归用例，并修复 SQLite filters 注入、OpenAI LLM、用户画像空字段等问题。
  • v1.1.2：增强配置与部署体验，支持自定义 memory 处理环境变量、内置默认 embedding 零配置启动、CLI / server / MCP / seekdb 可选依赖拆分，并补充多客户端集成指南与 Claude Code 安装流程。
  • v1.1.3：Dashboard 接入语义搜索，支持时间范围与排序；新增 CodeFuse IDE 支持，并优化记忆共享权限、遗忘记忆排序与 MCP 发布流程。
  • v1.1.4：检索 API 支持过滤条件，记忆列表支持按 scope 过滤；服务启动可自动打开 Dashboard，默认数据目录调整为 ~/.powermem，并优化记忆衰减与图谱隔离。
  • v1.1.5：支持 no-LLM 模式和 NoopEmbedding，embedding 模型下载内置到 PowerMem 并支持国内路由；新增 Claude Code Hook 隐私控制、coding-agent 观测与会话时间线 API，并开始发布插件与多平台二进制包。
  • v1.1.6：补齐中文文档与官网本地化，初始化流程支持交互问答与 remote-init；SQLite 默认面向 coding agent，发布单独二进制资产，并优化 MCP ID 精度、记忆保留字段与新鲜记忆检索。
  • v1.1.7：插件默认启用 transcript inference，精简 recall / remember skills；同时修复 powermem-mcp help 行为。

项目开源地址：https://github.com/oceanbase/powermem，欢迎试用、贡献 PR / Issue！

AgentSeek 发布 v0.0.2–v0.0.4

OceanBase AgentSeek 是基于 OceanBase & LangChain 打造的智能体工程套件，提供一系列工具和库，帮助开发者快速构建具备数据闭环能力的智能体飞轮。

AgentSeek v0.0.2–v0.0.4 持续加速 Agent 应用开发，从 LangChain / Agentic RAG 模板、OpenVINO 支持到一键技能安装与生命周期工具流，进一步把“快速搭建可运行 Agent”变成开箱即用的体验。

  • v0.0.2：强化 LangChain 友好体验，新增开发指南与多个模板，包括 sandbox、ContextSeek / Bub、deepagents content-builder。
  • v0.0.3：CLI 能力增强，支持查看版本、列模板、离线列技能、默认添加技能，并统一项目入口。
  • v0.0.4：新增 Agentic RAG / OpenVINO 模板，引入 Phoenix + SeekDB 到默认 LangChain 模板，优化生命周期工具流。

AgentSeek 相关均已开源，欢迎试用、贡献 PR / Issue！

  • AgentSeek：https://github.com/ob-labs/agentseek
  • AgentSeek-api：https://github.com/ob-labs/agentseek-api
  • ContextSeek：https://github.com/ob-labs/contextseek
  • langchain-oceanbase：https://github.com/oceanbase/langchain-oceanbase

社区动态

1. Agent 自进化的另一条路——让上下文成为活的数据资产

随着 Agent 落地生产环境，一个关乎业务的问题开始显现：如何让 Agent 系统随着使用持续进化？

6 月 8 日，OceanBase 社区联合 DataFun 社区开启技术直播，通过企业的前沿探索与一线技术实践，探讨“让 Agent 所处的上下文环境持续进化”，从而推动 Agent 能力的长期增长，即能记住、能检索、能引用、能复盘、能演进，并使上下文沉淀为核心数据资产。

2. 智能体落地方法论杭州沙龙

6 月 24 日，FastGPT 联合 OceanBase、上海斯歌 K2、Sealos、AskTable 在杭州黄龙国际中心举办“智能体落地方法论：从技术构建到企业落地”主题沙龙。

活动围绕智能体从 Demo 走向生产环境后的系统工程问题展开，聚焦数据孤岛打通、安全可控、从 POC 到规模化应用等企业落地挑战，通过 5 场主题分享和 1 小时圆桌交流，拆解金融、制造到消费行业的真实案例。详情可阅读：【活动回顾】从上海到杭州，FastGPT联合六大社区把Agent落进真实业务里

3. 从框架编排到数据飞轮：聊聊国内开发者构建 Agent 的新思路和新选择

多智能体应用已从实验走向生产，但“能跑通 Demo”和“能持续进化”之间，隔着一道国内开发者不得不面对的现实鸿沟：编排工具百花齐放，数据层却各自为政——上下文散了、trace 丢了、执行轨迹成了“一次性消耗品”，调试靠猜、优化靠运气、迭代靠重写。

6 月 25 日，OceanBase 与 CSDN 联合呈现了一场直播。 邀请到通义实验室 AgentScope 项目技术负责人与 LangChain 社区大使共同探讨：国内开发者当下最真实的工程选择。

4. OceanBase Hours 线上发布会

6 月 29 日，OceanBase Hours 线上发布会在多个平台直播，讲述 AI 时代 OceanBase 的新探索，并发布面向湖库一体的 AI 数据库。

详情可阅读：OceanBase 湖库一体 AI 数据库正式发布

社区课程共建招募

DataWhale x OceanBase 联合制作的社区课程《Easy Data x AI》共建招募中！

这不是又一份“从零开始学大模型”的资料，而是想把 Data 和 AI 之间那段最容易踩坑的路讲清楚。课程由 Datawhale 和 OceanBase 社区联合共建，目前已经有基础篇、产品视角的“道篇”，以及开发者视角的“术篇”。

课程地址：https://github.com/datawhalechina/easy-data-x-ai

现在，我们更想邀请社区一起把它继续写深、写准、写实用。欢迎大家来给这门课程补上一笔。参与课程共建的方式很简单：看一眼课程共建指南 https://github.com/datawhalechina/easy-data-x-ai/blob/main/CONTRIBUTING.md ，然后找到你感兴趣的 Issue，留言认领，写完提 PR。哪怕只是修一个事实错误，也算贡献；如果你独立完成扩展篇，还会有正式署名。

我们希望每一位参与者不仅留下贡献，也能收获成长。所有被合并 PR 的贡献者都会获得相应的社区实物激励。详见：一起补上 Agent 时代的数据基础课：Easy Data x AI 入门课程共建招募
