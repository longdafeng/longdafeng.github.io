OceanBase 社区月报：数据库内核与 AI 工具齐发版，技术活动覆盖多城

OceanBase 社区 8 月月报：AgentSeek 连发三版，内核 V4.4.2_CE_BP2 与 OBD v4.5.0 发布，并新增 15 款生态认证。

本期速览

  • OceanBase V4.4.2_CE_BP2、OBD v4.5.0 发布，强化高可用、数据同步与 AI 数据库部署

AI 应用开发套件——AgentSeek 发布三个版本

AgentSeek 是由 OceanBase 开源团队孵化的、面向 AI Agent 应用的开发套件。它以模板为起点，为开发者提供从应用发现、创建、检查、配置，到运行、观测和持续迭代的一套统一流程。开发者可以基于 DeepAgents、LangChain 等技术栈快速生成可自由修改的本地 Agent 项目，并按需集成模型、工具、MCP 服务和数据库能力，降低 Agent 应用从示例走向实际开发的门槛。

2026 年 7 月，AgentSeek 发布 v0.0.5、v0.1.0 和 v0.1.1 三个版本，主要变更包括：

  • v0.0.5 重点改善模板发现和项目创建体验，新增模板详情查看、关键词筛选和自定义输出目录等功能；同时加入 Agentic Hybrid RAG 模板，将沙箱模板迁移至 DeepAgents 并默认采用 Daytona，完善了 seekdb Agent Skills、LangChain 模板可观测能力，以及模板选择、编写、运行和项目生命周期等文档。
  • v0.1.0 是 7 月的里程碑版本，引入 Lifecycle v2，进一步规范项目服务发现和生命周期配置加载；支持显式配置模板目录仓库，并新增企业微信渠道，使 Agent 应用能够通过企业微信接收和回复消息。此外，该版本还增强了本地项目路径处理和环境变量隔离能力。
  • v0.1.1 主要提升跨平台运行和模板稳定性，包括完善 Windows 子进程管理和跨平台测试、修复 Daytona 沙箱工作区路径问题、让 LangChain Agentic RAG 模板默认使用嵌入式 seekdb，并新增 DeepAgents MCP 工具模板。

通过本月迭代，AgentSeek 在开发体验、模板生态、消息渠道、跨平台支持和 seekdb 集成等方面进一步完善，为开发者构建和运行本地 Agent 应用提供了更完整、稳定的工具链。

OceanBase 内核版本更新，进一步强化高可用与生产稳定性

版本信息：

  • 发布时间：2026 年 07 月 16 日
  • 版本号：V4.4.2_CE_BP2
  • RPM 版本号：oceanbase-ce-4.4.2.2-102000022026071514

本次版本的主要改进包括：

  • 增强高可用与容灾能力。 正式支持主备库强同步，实现 RPO=0，即故障发生时数据零丢失；新增最大保护和最大可用两种保护模式，并支持延迟备库，减少误删除、误更新等操作被立即同步至备库的风险。同时增加 per-LS 粒度监控视图和历史同步位点快照，帮助运维人员更准确地定位主备同步问题。
  • 升级数据同步架构。 OBCDC 从单机动态库演进为分布式服务化架构，支持通过水平扩展提升数据同步能力，更好地适应大规模数据订阅和变更数据捕获场景。同时优化 UPDATE 事件的拆分与合并逻辑，保障下游系统接收到一致的 CDC 语义。
  • 扩展 MySQL 模式兼容性。 新增 caching_sha2_password 认证插件支持，进一步改善与 MySQL 客户端和生态工具的兼容性；同时增加全角字符转半角字符函数，满足更多数据清洗和业务迁移需求。
  • 优化 SQL 和 PL 执行性能。 改进硬解析过程中的内存管理和 Plan Cache 诊断能力，并针对 JSON、Trigger 以及全局索引访问路径等场景进行性能优化，提升复杂业务负载下的执行效率和问题诊断能力。
  • 强化备份、归档和存储管理。 增加备份数据完整性校验，优化归档启停性能，并细化回收站任务调度机制，进一步提高备份恢复可靠性和存储空间管理效率。
  • 提升运行安全与自动化运维能力。 引入 Python UDF 沙箱隔离，降低用户自定义函数对数据库系统的影响；新增分库分表场景下的 Outline 自动绑定能力，减少人工配置成本，提升复杂生产环境中的 SQL 稳定性。

总体来看，V4.4.2_CE_BP2 在保持 V4.4.x 系列稳定性的基础上，进一步补齐了主备容灾、分布式数据同步和企业级兼容能力，并针对性能诊断、备份归档和安全隔离进行了系统性增强，为 OceanBase 在关键业务及大规模生产环境中的稳定运行提供了更扎实的支撑。

安装部署工具 OBD v4.5.0 发布

社区动态

1. WAIC 午餐会｜从云端 Agent 到端侧设备，让 AI 记得住、跑得快、更准确

7 月 19 日，社区在 2026 年世界人工智能大会期间，围绕会场关注点极高的具身智能，开办了一场“午餐会”，以智能驾驶场景为例展示了 OceanBase 的技术方案，并在现场引导开发者进行 workshop，2 小时 get：

  • 在云端，Agent 拥有长期记忆与检索精准度提升方案
  • 在端侧，具身智能与自动驾驶不再受限于硬件算力与存储瓶颈，实现实时感知与决策

2. Agent 从 Demo 到生产，差的不是模型，而是没有记忆

7 月 31 日，社区来到苏州，围绕 Agent Runtime 的关键技术栈展开，讨论如何构建面向企业、符合信创要求、可持续运行的 Agentic AI 基础设施，并探索用户场景。

3. 八月活动预告

8 月 15 日，社区将联合海外友商 Percona 在中关村举办一场以数据库为主的技术交流。主题为：兼容还是重构？AI 时代下数据库的“危”与“机”。

欢迎通过报名链接 https://open.oceanbase.com/activities/4924119 进行报名：

当全行业的目光聚焦于大模型与 AI 应用时，有一群人清醒地知道：算力诚可贵，数据价更高。 没有极致的数据库底层，所有的智能都是空中楼阁。到场嘉宾包括但不限于：

  • 两位 Percona Founder，分别是 Peter Zaitsev、Vadim Tkachenko；
  • 华为云云原生数据库引擎首席架构师彭立勋，其也是 CCIA 专委会副会长兼 ACMUG 主席；
  • 数据库专家杨建荣，DBAplus 社群发起人之一。《Oracle DBA 工作笔记》《MySQL DBA 工作笔记》作者；
  • 滴滴数据库负责人王广友；
  • OceanBase CTO 杨传辉。

这场技术 meetup，我们摒弃浮躁，回归“源力”。在数据库的璀璨星河中，MySQL 依然是那颗最闪亮的恒星。因此，我们集结了 MySQL 生态的“半壁江山”——从国际社区的灵魂人物到国产数据库的掌舵人，从云原生的引领者到企业级服务的深耕者。不谈空泛的概念，只聚焦三个核心追问：

  • AI 如何让数据库变得更聪明？（AI for DB）
  • 数据库如何更好地支撑 AI 应用？（DB for AI）
  • MySQL 生态的下一个十年有哪些坚守与变革？

核心看点：

  • 全球 MySQL 生态“半壁江山”首次同台，探讨 AI 时代数据库的范式革命
  • AI 与数据库的真实结合点，区分“能做的”与“在吹的”，降低选型试错成本
  • 国际社区与国产自研的技术路线分歧与融合趋势，以及 AI 对数据库内核的潜在改造方向
  • AI 辅助运维（AIOps）的真实落地现状——哪些工具已经可用，哪些还是概念?

我们每个月都会和大家展开一次社区进展的汇报沟通会，希望通过更多的互动交流让 OceanBase 开源社区更加透明，实现信息共享，也希望能营造更加轻松的氛围，为大家答疑解惑，让大家畅所欲言。
