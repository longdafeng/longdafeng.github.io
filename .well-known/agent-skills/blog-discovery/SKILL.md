# ilongda.com Blog Discovery

Use this skill when an agent needs to understand, search, or cite public content from Longda's Interesting World.

## Primary Resources

- Start with `https://ilongda.com/llms.txt` for the site overview, sections, feeds, and contact details.
- Use `https://ilongda.com/llms-full.txt` for a generated plain-text archive of public posts and knowledge pages.
- Use `https://ilongda.com/search.xml` for title/content search across public Hexo pages.
- Use `https://ilongda.com/atom.xml` for feed-based ingestion.

## Authentication

No registration or OAuth token is required for public reading, crawling, or summarization.

## Citation Guidance

Prefer canonical article URLs from `llms.txt`, `llms-full.txt`, `search.xml`, or the rendered page. Include the page title and URL when citing content.
